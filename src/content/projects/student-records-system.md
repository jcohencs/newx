## The brief

Design and build a relational database system for managing student records — the kind of system a registrar's office might use — from schema design through a working application layer.

## What I built

- An ER diagram and fully normalized schema (3NF) covering students, courses, enrollments, and grades
- A set of SQL queries for common operations: enrollment lookups, grade reporting, and aggregate statistics
- Full CRUD operations (create, read, update, delete) exposed through an application layer
- Basic user authentication to separate access by role

## Takeaway

This project was where database theory turned into something concrete — thinking through normalization tradeoffs, foreign key relationships, and query performance instead of just reading about them.
