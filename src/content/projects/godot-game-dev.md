## Why Godot

Game dev is my creative outlet outside of IT work — there's something satisfying about building small systems that interact with each other in interesting ways, with immediate, visible feedback.

## What I built

A set of 2D and 3D prototypes in Godot, used to learn the engine's core systems end to end rather than following a single tutorial project.

## Systems implemented

- **NPC AI & pathfinding** — basic state-driven enemy/NPC behavior with navigation across TileMap-based levels
- **TileMaps & level layout** — modular level design using Godot's tile system
- **Physics & lighting** — 2D/3D physics bodies, collision layers, and dynamic lighting setups
- **Scene architecture** — reusable, modular scenes and scripts rather than one monolithic game file

## Takeaway

Working through these systems from scratch gave me a much better handle on how game engines structure state, rendering, and input — lessons that carry over directly into how I think about any interactive system, including the internal tools I build at work.
